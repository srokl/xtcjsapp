Add ability to combine multiple uploaded images into a single XTC or
XTCH container file from the image converter page.

- Add "Pack all images into single .xtc/.xtch" checkbox in image mode
  Options panel, with conditional sub-options (WASM, streamed download,

- Add early-return batch path in ConverterPage that bypasses per-file
  loop when packToXtc is active, calling the new batch function with
  all selected files at once
